# Wiki biostatistiek

De [wiki biostatistiek](https://github.com/pdmoerland/wiki-biostatistiek/wiki) van Amsterdam UMC
geeft antwoorden op veelgestelde vragen over statistiek in medisch onderzoek.
De inhoud staat in de wiki van deze repository en is in september 2026 gemigreerd van de oude
MediaWiki (wikistatistiek.amc.nl).

## Structuur

- Elke wikipagina is een Markdown-bestand; de bestandsnaam is de paginatitel (`Lineaire-regressie.md` → pagina *Lineaire regressie*).
- `Home.md` is de startpagina, `_Sidebar.md` de inhoudsopgave per thema.
- Afbeeldingen en bijlagen (PDF, DOC) staan in de hoofdmap van de wiki.

## Bewerken

Bewerk de pagina's op GitHub, of clone de wiki-repository:

```
git clone https://github.com/pdmoerland/wiki-biostatistiek.wiki.git
```

- Interne links zonder `.md`: `[t-toets](T-toets)`.
- Gebruik decimale komma's in de tekst (0,05, niet 0.05).
- Nieuwe pagina? Voeg hem ook toe aan `_Sidebar.md` en, waar passend, aan `Home.md`.
